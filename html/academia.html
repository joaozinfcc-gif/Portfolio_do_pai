Academia BoaForma.

Projeto acadêmico de modelagem e implementação de um banco de dados relacional para gerenciar alunos, planos, turmas, pagamentos e fichas de treino.

O problema e a solução

O banco organiza o cadastro de alunos e instrutores, inscrições em turmas, pagamentos, frequência e exercícios. Chaves primárias, estrangeiras e tabelas associativas mantêm os relacionamentos entre os registros.

Exemplo de consulta

alunos_e_planos.sql
SELECT a.nome AS aluno,
       p.nome AS plano,
       p.valor_mensal
FROM aluno a
INNER JOIN plano p
  ON a.id_plano = p.id_plano
ORDER BY a.nome;

O INNER JOIN relaciona cada aluno ao seu plano utilizando a chave estrangeira.

Regras de negócio

  • Reativação automática de alunos inativos após pagamento.
  • Validação de vagas antes de uma inscrição.
  • Cadastro de alunos com verificação de CPF duplicado.
  • Relatórios de receita mensal e alunos com pagamentos pendentes.

Scripts do projeto

Execute na ordem indicada no MySQL Workbench. Os dados são fictícios e a última instrução do terceiro script provoca intencionalmente um erro de turma lotada. Atenção: o primeiro script apaga e recria o banco de teste.
