Banco de dados

Consulta de estoque.

No projeto de banco de dados da faculdade, trabalhei com uma loja de informática. Nesta demonstração, o JavaScript liga cada produto à sua categoria pelo ID. A consulta mostra como escrever a mesma operação em SQL.

consulta.sql
SELECT p.nome, c.nome AS categoria, p.quantidade
FROM produto AS p
JOIN categoria AS c ON c.id = p.categoria_id
ORDER BY p.nome;
