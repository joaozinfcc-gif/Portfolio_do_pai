Banco de dados

Consulta de estoque.

Esta é uma demonstração complementar de banco de dados para uma loja de informática. Nesta demonstração, o JavaScript liga cada produto à sua categoria pelo ID. A consulta mostra como escrever a mesma operação em SQL.

consulta.sql
SELECT p.nome, c.nome AS categoria, p.quantidade
FROM produto AS p
JOIN categoria AS c ON c.id = p.categoria_id
ORDER BY p.nome;
