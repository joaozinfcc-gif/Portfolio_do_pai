Consulta de estoque.

Este exercício demonstra um JOIN em uma loja fictícia. O JavaScript liga cada produto à sua categoria pelo ID e exibe a consulta SQL equivalente.

consulta.sql
SELECT p.nome, c.nome AS categoria, p.quantidade
FROM produto AS p
JOIN categoria AS c ON c.id = p.categoria_id
ORDER BY p.nome;
